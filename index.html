01 / APPLICATION

從參與方申請到人民查驗

加入 MJVS 不會自動與所有參與方互免。每一項互惠安排都須由雙方逐一同意，並依公告的生效日與範圍適用。

  1. 01

    在 DC 提出申請

    參與方提交加入資料、代表與聯絡窗口，並說明希望洽談的互惠對象。

  2. 02

    檢查資料完整性

    管理機關檢視申請與履行方式；資料不足時，通知補件或修正。

  3. 03

    逐一協商互惠條款

    雙方確認適用人員、目的、停留上限、生效日期、例外及查驗安排，並留下可查證的書面同意。

  4. 04

    通過並公告生效

    至少一份互惠協議生效後，參與方才可登記為免簽國；未公告生效前，不得宣稱待遇已開始。

  5. 05

    建立 ID，按目的地查驗

    人民取得個人 ID 後，目的地可查詢該 ID 的登記狀態及對應的有效互惠條件。

狀態連動：若參與方已沒有任何生效中的互惠協議，其免簽國身分轉為「暫停」；恢復至少一份有效協議後，才可恢復有效狀態。協議狀態彼此獨立。

03 / ID ISSUANCE

兩種 ID 建立方式

參與方通過審核後，可由人民個別申請，或由該方提供名單交由 MJVS 建立。無論採哪種方式，公開查驗都只回覆單筆 ID 所需資訊。

ROUTE A 個人申請

人民持護照，向 MJVS 申請個人 ID

  1. 透過正式、受限制的私人渠道提出申請。
  2. 由授權承辦人查驗護照並核對申請資格。
  3. 核對完成後發給個人 ID；護照影像與號碼不進入公開查驗結果。

本示範網站沒有護照上傳欄位，也不會收集或保存護照資料。

ROUTE B 參與方名單

參與方直接交付 ID 名單

  1. 由參與方指定代表透過私密、受控渠道交付名單。
  2. MJVS 管理人員在受限環境匯入並建立個人 ID 記錄。
  3. 公開端只支援單筆查驗，不提供名單瀏覽、下載或批次查詢。

名單匯入介面與權限控管尚未建置；請勿在公開網站張貼或上傳名單。

06 / SAFEGUARDS

查驗原則與資料邊界

01

不公開護照資料

護照只供個人申請時由授權人員私下核驗；公開查驗不展示護照號碼、影像或其他證件欄位。

02

不公開整份 ID 名單

公開端只允許單筆查詢；不得瀏覽、下載、列舉或批次取得全部 ID。

03

互惠不是自動擴張

每一組參與方都要有各自有效的互惠協議；一份協議的變更不會自動改變其他協議。

04

查詢不是入境保證

MJVS 名稱與協議不等於外交或主權承認，也不取代目的地的入境規則及個案審查。
