DATA & STATUS

資料與查驗狀態

01

只查 ID、國家與狀態

查驗 API 只請求試算表的 id、country_name、status 欄；僅在 ID 有效時顯示國家，不提供名錄列表或批次查詢。

02

來源試算表可公開檢視

知道試算表連結的人可以查看整份表格與所有欄位。請勿在表格中放入護照號碼、護照影像或其他不應公開的資料。

03

空名錄或資料不完整不等於查無

名錄為空或 id、country_name、status 任一必要欄位未填時，頁面顯示無法確認；只有完整名錄可讀時，才會判定 ID 有效或顯示「沒有在免簽名單之內」。
