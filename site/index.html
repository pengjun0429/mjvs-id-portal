01 / APPLICATION

從參與方申請到 ID 查驗

加入 MJVS 不會自動與所有參與方互免。每一項互惠安排都須由雙方逐一同意，並依公告的生效日、範圍及例外適用。

  1. 01

    在 Discord 聯絡 MJVS

    參與方代表透過 MJVS Discord 查看最新申請公告與聯絡方式。

  2. 02

    檢查申請資料

    管理機關檢視參與方、代表、履行方式與預定互惠對象；資料不足時通知補充。

  3. 03

    逐一協商互惠條款

    雙方確認適用人員、訪問目的、最長停留期限、生效日期、例外及查驗安排，並留下可查證的書面同意。

  4. 04

    核准並公告生效

    至少一份互惠協議生效後，參與方才可登記為免簽國；未公告生效前，不得宣稱待遇已開始。

  5. 05

    建立 ID，按目的地查驗

    完成核驗後建立個人 ID。目的地可逐筆查驗 ID 有效性；實際待遇仍依該目的地與來源方之有效協議判斷。

狀態連動：若參與方已沒有任何生效中的互惠協議，其免簽國身分轉為「暫停」；恢復至少一份有效協議後，才可恢復有效狀態。協議狀態彼此獨立。

02 / PARTICIPANT APPLICATION

參與方申請準備

依 MJVS 規章草案第七條整理。最新受理方式與時程以 Discord 公告為準；請勿在公開頻道張貼私人文件。

  • 參與方名稱、簡介與官方聯絡方式
  • 主要代表的姓名、職務與聯絡方式
  • 希望建立互惠安排的對象
  • 適用對象、訪問目的、最長停留期限與生效日期
  • 例外情形、入境審查與事件聯絡窗口
  • 對 MJVS 規章及個別協議的書面同意

聯絡入口

MJVS Discord

03 / ID ISSUANCE

兩種 ID 建立方式

參與方核准後，可由人民個別申請，或由該方透過受控流程提供 ID 名單。ID 核發仍須由授權管理流程處理。

ROUTE A 個人申請

人民持護照，向 MJVS 申請個人 ID

  1. 先透過 Discord 聯絡，依管理員指示使用私人受控渠道。
  2. 由授權承辦人私下核對申請資格與護照。
  3. 核對完成後發給個人 ID；護照影像與號碼不進入公開查驗服務。

本網站沒有護照上傳欄位；請勿在公開 Discord 頻道傳送護照資料。

ROUTE B 參與方名單

由參與方建立並維護 ID 名錄

  1. 名錄目前以公開 CSV 試算表作為唯一查驗來源。
  2. 任何取得試算表連結的人都能檢視整份表格與所有欄位；請勿填入護照或其他未授權的敏感資料。
  3. 網站查驗 API 只比對 ID 與狀態欄，不回傳姓名或國家，也不提供列表或批次查詢。

網站 API 的單筆回覆不代表來源試算表是私密的；名錄連結持有者可直接查看完整內容。

04 / PUBLIC ID LOOKUP

單筆 ID 有效性查驗

輸入一個 ID，只回覆有效、查無或無法確認；網站 API 不顯示姓名、國家或護照資料，也不提供列表或批次查詢。來源 CSV 本身可由連結持有者檢視。

正在確認名錄狀態。查驗輸入只會以同源 POST 傳送；不會放入網址。不要輸入護照號碼、姓名或其他個人資料。

!

正在確認名錄狀態；名錄為空時不會回覆「沒有在免簽名單之內」。

ID 有效不代表自動適用免簽。目的地仍須依來源參與方、旅行目的、日期、有效互惠協議與例外判斷；查驗結果不保證個案一定獲准入境。

05 / RECIPROCITY

互惠安排依協議逐一確認

免簽國身分與個別互惠協議分開管理。加入 MJVS 不代表自動與所有參與方互免；未列入有效公告或有效協議的關係，不得視為已生效。

協議公告

本網站目前沒有載入可核驗的生效協議資料，因此不列出任何免簽安排。請依雙方正式公告或向官方聯絡窗口確認。

每份正式協議須列明雙方、適用人員與目的、最長停留、多次入境條件、生效與終止方式、例外及聯絡窗口。

06 / SAFEGUARDS

查驗原則與資料邊界

01

不在網站查驗中收集護照

護照只供授權承辦人依受控流程核驗；網站不接收、不展示護照號碼或影像。

02

網站回覆只含 ID 狀態

API 不回傳姓名、國家或整份名錄；但目前來源 CSV 是公開可讀，連結持有者能檢視其所有欄位。請勿在其中存放護照或未授權的敏感資料。

03

互惠不會自動擴張

每一組參與方都要有各自有效的互惠協議；一份協議的變更不會自動改變其他協議。

04

查驗不是入境保證

MJVS 名稱與協議不等於外交或主權承認，也不取代目的地的入境規則及個案審查。

SERVICE STATUS

公開入口已建立；查驗狀態依名錄內容更新。

名錄有至少一筆格式正確的 ID/status 記錄時，頁面會自動啟用查驗。名錄為空、欄位不完整或來源無法讀取時，只會顯示「名錄尚未啟用／無法確認」，不會對空名錄作出查無判定。本站內容依 MJVS 規章草案第 3 版整理；正式待遇以雙方已生效協議與正式公告為準。
